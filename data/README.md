# Corpus documents

The source PDFs are **not** committed (see `.gitignore`). Place them in
`data/raw/` with the exact filenames below — `src/ingestion/corpus.py` keys
on them. `data/processed/` is generated by `uv run python -m src.bootstrap`
(or the docker-compose `indexer` service) and never edited by hand.

Notes:

- EUR-Lex and ISAP texts are official publications; the EDPB Opinion 28/2024
  Polish file is an **unofficial translation** and is flagged as such in
  chunk metadata and in the UI.
- Laws get amended. The Labour Code consolidation in use is dated 2026-04-16
  and the Ukrainian law 2025-06-14 (recorded as `consolidated_as_of` in
  `src/ingestion/corpus.py`); if you download newer consolidations, update
  those fields and rebuild the indexes.
- After placing the PDFs: `uv run python -m src.bootstrap` parses, chunks,
  and indexes everything; `uv run python -m src.ingestion.validate_corpus`
  verifies the result.
